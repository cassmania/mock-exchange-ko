# 모의 거래소 연습장

가상 자금 1억 USDT로 현물, 선물, 예치, 대출, 봇을 연습하는 한국어 정적 사이트입니다.

- 실제 거래소가 아니며 MEXC 등 어떤 거래소와도 관련이 없습니다. 메뉴 구조만 참고했습니다.
- 실제 돈, 주문, 계정과 연결되지 않습니다. 계정 정보, 카드 번호, 입금 주소를 받지 않습니다.
- 잔고와 내역은 브라우저에만 저장되며, 상단의 리셋 버튼으로 처음 상태로 돌아갑니다.
- 일부 코인 시세는 Binance 공개 API에서 받고, 나머지 종목과 연결 실패 시에는 무작위 가격을 씁니다.
- 수수료, 이율, 보상은 연습용 임의 값입니다. 투자 조언이 아닙니다.

계산 검사: `node sim-engine.test.js`
